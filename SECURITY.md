# 🔐 Security Policy

## Supported Versions

This project is currently maintained on the latest version available in the repository.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older versions | ❌ |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, credential exposure, or other security-related issue in this project, please report it privately to the project maintainer.

Please do not publicly disclose sensitive information such as:

- API keys
- Kaggle credentials
- Access tokens
- Passwords
- Private datasets
- Environment variables
- Other sensitive configuration

---
